# OpsTether Linux Operations — free companion skill

A free, text-only agent skill for evidence-first Linux inspection and approved operations through OpsTether MCP.

**Important:** OpsTether is a **separate hosted service**. Agensi does not host the server. The skill does **not** include an account, server access, Linux installer, OAuth credentials or guaranteed client integration. Connect `https://opstether.m2g.pro/mcp` separately through a supported OAuth-enabled MCP client and pair your own authorized Linux server.

The skill explains server selection, safe resource/systemd/Docker diagnostics, bounded logs, explicit approval of changes, and careful handling of privileged operations.
